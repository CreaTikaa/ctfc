# How it works

The plain-language explanation of every module lives in
[`ctfc/data/how-it-works.md`](../ctfc/data/how-it-works.md), so that it ships
with the package and is readable offline - from `ctfc serve`'s **Docs** tab on
the day of the CTF, with no network and no copy of this repository.

Same reason as [`cheatsheet.md`](cheatsheet.md): a document you cannot open
while the challenge is running is a document you do not have.
